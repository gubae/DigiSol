💻 Algorithms & Programming

Problem-solving methodologies, pseudocode, flowcharts, and Python programming fundamentals – Unit 3.

1. Problem-Solving Approach

Digital Solutions uses a structured approach to solving problems:

  1. Define the problem – understand what is needed.
  2. Plan the solution – design an algorithm using pseudocode or flowchart.
  3. Implement the solution – write the code.
  4. Test and evaluate – verify the solution works for all cases.
💡 Algorithm: A precise, step-by-step set of instructions for solving a problem or completing a task.

2. Pseudocode

Pseudocode uses plain English to describe an algorithm – it is not a programming language, but it is structured.

Common Pseudocode Conventions (QCAA style)

BEGIN
  INPUT name
  IF name = "Alice" THEN
    DISPLAY "Welcome back, Alice!"
  ELSE
    DISPLAY "Hello, " + name
  END IF
END

Loops in Pseudocode

FOR count ← 1 TO 5
  DISPLAY count
END FOR

WHILE score < 100
  score ← score + 10
END WHILE

3. Flowcharts

Flowcharts use standard symbols to represent an algorithm visually.

  • Oval (Terminator) – START or END.
  • Parallelogram (I/O) – INPUT or OUTPUT.
  • Rectangle (Process) – calculations or assignments.
  • Diamond (Decision) – YES/NO or TRUE/FALSE branch.
  • Arrows – show the flow of control.

4. Python Fundamentals

Variables and Input

name = input("What is your name? ")
age = int(input("How old are you? "))
print("Hello,", name, "– you are", age, "years old.")

Conditional Statements

score = int(input("Enter score: "))
if score >= 90:
    print("A")
elif score >= 75:
    print("B")
elif score >= 60:
    print("C")
else:
    print("Below C")

For Loops

for i in range(1, 6):
    print(i)          # prints 1, 2, 3, 4, 5

fruits = ["apple", "banana", "mango"]
for fruit in fruits:
    print(fruit)

While Loops

count = 0
while count < 5:
    print(count)
    count += 1

Functions

def greet(name):
    return "Hello, " + name + "!"

message = greet("Alice")
print(message)   # Hello, Alice!

Lists

marks = [85, 92, 78, 65, 90]
print(len(marks))       # 5
print(max(marks))       # 92
print(sum(marks) / len(marks))  # average

File I/O

# Writing to a file
with open("data.txt", "w") as f:
    f.write("Hello, file!\n")

# Reading from a file
with open("data.txt", "r") as f:
    content = f.read()
    print(content)

5. Searching & Sorting Algorithms

Linear Search

Check each element one by one until the target is found. Time complexity: O(n).

def linear_search(lst, target):
    for i in range(len(lst)):
        if lst[i] == target:
            return i
    return -1

Binary Search

Requires a sorted list. Halves the search space each step. Time complexity: O(log n).

def binary_search(lst, target):
    low, high = 0, len(lst) - 1
    while low <= high:
        mid = (low + high) // 2
        if lst[mid] == target:
            return mid
        elif lst[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1

Bubble Sort

Repeatedly swaps adjacent elements that are out of order. Time complexity: O(n²).

def bubble_sort(lst):
    n = len(lst)
    for i in range(n):
        for j in range(0, n - i - 1):
            if lst[j] > lst[j + 1]:
                lst[j], lst[j + 1] = lst[j + 1], lst[j]
    return lst
