📊 Data & Information

Data types, structures, databases, and transforming raw data into meaningful information – Unit 1.

1. Data vs Information

  • Data – raw, unprocessed facts with no context. Example: 42, Brisbane, Y.
  • Information – data that has been processed and given meaning. Example: "The temperature in Brisbane today is 42 °C."

The process of turning data into information involves collecting, organising, analysing, and presenting data.

Attributes of Quality Information

  • Accuracy – free from errors.
  • Completeness – all necessary data is present.
  • Currency – up-to-date and relevant.
  • Relevance – appropriate for the purpose.
  • Consistency – uniform format and meaning.

2. Data Types

In programming and databases, every piece of data has a type that defines how it is stored and used.

Type Description Example
Integer Whole numbers (no decimal) 42, -7
Float / Real Numbers with a decimal point 3.14, -0.5
String Text characters "Hello"
Boolean True or False True
Date / Time Dates and times 2025-11-05

3. Data Structures

Arrays / Lists

An ordered collection of values stored at numbered index positions (starting at 0).

students = ["Alice", "Bob", "Charlie"]
print(students[0])   # Alice
print(students[2])   # Charlie

Dictionaries (Key-Value Pairs)

Store data as paired keys and values, like a real dictionary.

student = {"name": "Alice", "age": 17, "grade": "A"}
print(student["name"])   # Alice

Two-Dimensional Arrays

A grid/table of values – like rows and columns in a spreadsheet.

grid = [[1, 2, 3],
        [4, 5, 6],
        [7, 8, 9]]
print(grid[1][2])   # 6  (row 1, col 2)

4. Relational Databases

A relational database stores data in tables (called relations). Tables are linked using keys.

Key Concepts

  • Table (Relation) – a grid of rows and columns.
  • Row (Tuple / Record) – a single data entry.
  • Column (Attribute / Field) – a property being stored.
  • Primary Key (PK) – uniquely identifies each row in a table.
  • Foreign Key (FK) – links a row in one table to a row in another table.

SQL Basics

-- Select all students
SELECT * FROM Students;

-- Select students with grade A
SELECT Name, Age FROM Students WHERE Grade = 'A';

-- Insert a new record
INSERT INTO Students (Name, Age, Grade) VALUES ('Alice', 17, 'A');

-- Update a record
UPDATE Students SET Grade = 'B' WHERE Name = 'Bob';

-- Delete a record
DELETE FROM Students WHERE Name = 'Charlie';
💡 Remember: SQL keywords are conventionally written in UPPERCASE, but most databases are case-insensitive.

5. Key Terms Checklist

  • Data, information, knowledge
  • Integer, float, string, boolean
  • Array, list, dictionary, 2D array
  • Table, row, column, primary key, foreign key
  • SQL: SELECT, WHERE, INSERT, UPDATE, DELETE
  • Data quality: accuracy, completeness, currency
