🔒 Networks & Cybersecurity

Network architectures, protocols, threats, and strategies to protect digital assets – Unit 2.

1. What is a Network?

A computer network is two or more devices connected together to share data and resources.

Types of Networks

  • LAN (Local Area Network) – covers a small area (e.g. a school or home).
  • WAN (Wide Area Network) – covers large geographic areas. The Internet is the world's largest WAN.
  • WLAN (Wireless LAN) – a LAN using Wi-Fi (no physical cables).
  • PAN (Personal Area Network) – very small; e.g. Bluetooth devices around a person.

Network Topologies

  • Star – all devices connect to a central switch/hub. Most common in schools.
  • Bus – all devices share a single cable (older technology).
  • Ring – devices connect in a circle.
  • Mesh – every device connects to every other device (high redundancy).

2. Protocols

A protocol is a set of rules for how data is formatted and transmitted over a network.

Key Protocols

  • TCP/IP – the fundamental suite that governs internet communication.
  • HTTP / HTTPS – transfers web pages (HTTPS is the secure, encrypted version).
  • FTP – transfers files between computers.
  • SMTP / POP3 / IMAP – send and receive email.
  • DNS (Domain Name System) – translates domain names (e.g. google.com) into IP addresses.
  • DHCP – automatically assigns IP addresses to devices on a network.

The TCP/IP Model (4 Layers)

  1. Network Access – physical transmission of bits.
  2. Internet – IP addressing and routing.
  3. Transport – reliable delivery (TCP) or fast, unreliable delivery (UDP).
  4. Application – HTTP, FTP, DNS, SMTP, etc.

IP Addresses

Every device on a network has an IP address that uniquely identifies it.

  • IPv4: 32-bit, written as four numbers. Example: 192.168.1.1.
  • IPv6: 128-bit, written in hexadecimal. Example: 2001:0db8::1.
  • Public IP – visible on the internet.
  • Private IP – used inside a LAN (e.g. 192.168.x.x).

3. Cybersecurity Threats

Common Attack Types

  • Malware – malicious software (viruses, worms, trojans, ransomware, spyware).
  • Phishing – deceptive emails/messages that trick users into revealing credentials.
  • Man-in-the-Middle (MitM) – attacker intercepts communication between two parties.
  • Denial of Service (DoS / DDoS) – flooding a server with traffic to make it unavailable.
  • SQL Injection – inserting malicious SQL code into an input field to manipulate a database.
  • Social Engineering – manipulating people psychologically rather than attacking systems.
⚠️ Remember: Humans are often the weakest link in cybersecurity. Always verify the sender before clicking links.

4. Protection Strategies

Technical Controls

  • Firewalls – filter incoming and outgoing network traffic.
  • Encryption – converts data into an unreadable format. Only authorised parties with a key can decrypt it.
  • Authentication – passwords, multi-factor authentication (MFA), biometrics.
  • Antivirus / Anti-malware – detect and remove malicious software.
  • VPN (Virtual Private Network) – creates an encrypted tunnel over a public network.
  • Updates and Patches – fix known vulnerabilities in software.

Encryption Types

  • Symmetric encryption – same key for encryption and decryption (faster). Example: AES.
  • Asymmetric encryption – public key encrypts; private key decrypts. Example: RSA.
  • Hashing – one-way transformation, used for passwords. Example: SHA-256.

The CIA Triad

  • Confidentiality – data accessible only to authorised users.
  • Integrity – data is accurate and unaltered.
  • Availability – data is accessible when needed.
