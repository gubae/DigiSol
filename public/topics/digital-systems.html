🖥️ Digital Systems

Hardware, software, data representation, and how computers process information – Unit 1.

1. Hardware Components

A computer system is made up of hardware (physical components) that work together to process data.

Central Processing Unit (CPU)

The CPU is the "brain" of the computer. It fetches, decodes, and executes instructions using the Fetch–Decode–Execute cycle.

  • Control Unit (CU) – directs the flow of data and instructions.
  • Arithmetic Logic Unit (ALU) – performs calculations and logical comparisons.
  • Registers – small, extremely fast temporary storage inside the CPU.
  • Cache – small, fast memory that stores frequently used data.

Memory

  • RAM (Random Access Memory) – volatile, temporary working memory.
  • ROM (Read-Only Memory) – non-volatile, stores firmware/BIOS.
  • Secondary Storage – HDD, SSD, USB drives (permanent storage).

Input / Output Devices

  • Input: keyboard, mouse, microphone, camera, scanner, sensors.
  • Output: monitor, speakers, printer, projector.
  • Both: touchscreen, network interface card (NIC).

2. Data Representation

Computers store all data as binary (base-2) numbers using only 0s and 1s.

Number Systems

  • Binary (base-2): digits 0–1. Example: 1010 = 10 in decimal.
  • Decimal (base-10): digits 0–9.
  • Hexadecimal (base-16): digits 0–9 and A–F. Example: FF = 255 in decimal.

Converting Binary to Decimal

Use place values (powers of 2): 128, 64, 32, 16, 8, 4, 2, 1.

Example: 0110 1001
= 0×128 + 1×64 + 1×32 + 0×16 + 1×8 + 0×4 + 0×2 + 1×1
= 64 + 32 + 8 + 1 = 105

Units of Storage

  • 1 bit = a single 0 or 1
  • 8 bits = 1 byte
  • 1024 bytes = 1 kilobyte (KB)
  • 1024 KB = 1 megabyte (MB)
  • 1024 MB = 1 gigabyte (GB)
  • 1024 GB = 1 terabyte (TB)

Representing Characters – ASCII & Unicode

ASCII (American Standard Code for Information Interchange) maps 128 characters to 7-bit codes. Unicode extends this to cover every character in every language.

3. Software

Software is the set of instructions that tell hardware what to do.

Types of Software

  • System Software – manages hardware (e.g. operating systems, device drivers).
  • Application Software – performs specific tasks for users (e.g. word processors, games, browsers).
  • Utility Software – maintains and optimises the system (e.g. antivirus, disk cleaners).

Operating System Functions

  • Process management (scheduling CPU time)
  • Memory management (allocating RAM)
  • File system management
  • Input/output device management
  • User interface (GUI or CLI)

  • CPU, ALU, CU, register, cache

  • ASCII, Unicode, encoding
  • Operating system, application software, utility software
  • Input device, output device
